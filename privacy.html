対象

本ツールは開発者本人だけが、本人の Google アカウントに対して使う個人用ツールです。第三者の利用は想定していません。

アクセスするデータ

  • Gmail：メールのヘッダ（差出人・件名・日付など）と本文の一部、ラベル、フィルタ設定
  • Google カレンダー：本ツールが作成する予定

利用目的

メールの分類・ラベル付け・アーカイブ、フィルタの作成、本人の予定のカレンダー登録のためだけに使います。メールを削除することはありません。

保存と共有

  • 処理は本人の PC 上で行い、認証トークンと処理記録もその PC 内にのみ保存します。
  • データを販売・共有・第三者へ送信することはありません。広告にも使いません。
  • Google API から取得したデータの利用は、Google API Services User Data Policy（Limited Use 要件を含む）に従います。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」からいつでも取り消せます。

English summary

This is a personal tool used only by its developer on their own Google account. It reads Gmail headers and parts of messages, labels and filters to label, archive and filter mail (it never deletes mail), and creates events in the developer's own Google Calendar. All processing and storage happen on the developer's own computer. No data is sold, shared, sent to third parties or used for advertising. Use of data from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
